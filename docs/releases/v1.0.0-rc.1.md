# Meshcopia 1.0.0-rc.1

人間とAIエージェントが素材を探して使える、CC BY 4.0のライブラリ。

- オリジナル3Dモデル8点（GLB・OBJ/MTL・STL）とシームレス素材6点（1024px・4マップ）。
- 大きなサムネイル、検索・カテゴリー・種類・並び替え、モバイル対応。
- Three.jsの3Dクイックプレビュー、回転・拡大・材質・照明・ワイヤー。
- テクスチャの1×1/2×2/4×4とPBR球体プレビュー。
- 全体ZIP、モデルのみZIP、単体ダウンロード。CC BYクレジット同梱・コピー。
- JSON/NDJSON、個別マニフェスト、SHA-256。`_inbox`から自動取り込み。

検証: メタデータ・GLB/STL構造、検索、ZIP、ハッシュ、内部リンク、全24テクスチャマップの両端一致、CI Chromiumの操作試験に合格したコミットから作成。

制限: 初期素材は軽量なプロシージャル素材です。写真スキャンや写実品質ではありません。3Dプリント・機構用途は未検証。FBX/STEP対応は継承実装で、初期データに該当ファイルがないためブラウザ実データ試験の対象外です。STEP変換はブラウザで実行され、大きなCADは時間を要します。
