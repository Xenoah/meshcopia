# Meshcopia 1.5.0 — Street infrastructure and pedestrian access

## 日本語

- 街路設備と歩行者のアクセスを支える独自モデル 12 点を追加。全体は 131 素材（95 モデル、36 テクスチャ）、街コレクションは累計 24 モデルです。
- メートル・Y-up の静的 GLB と STL、実際のモデルから描画したサムネイル、用途と限界を明記したメタデータ、CC BY 4.0 と作者表示を収録。STL 自体には単位情報がありません。
- 累計 226 ZIP のハッシュを固定し、先行 202 ZIP の内容・URL・ハッシュを維持します。既存素材のファイルは変更せず、新規 ZIP に選択的な可逆圧縮を適用します。
- 制作元コード、依存関係と再生成手順を追加し、ZIP 生成環境を Node.js 22.23.3 に固定します。通常のサイトビルドでは、確認済みのモデルを再生成しません。
- 公開はリポジトリのワークフローによる検証を条件とし、素材・ZIP・リンク・テクスチャとブラウザ操作を確認します。Unity 等のエンジン互換性、実機 FPS、製造・構造・3D プリント用途の検証は含みません。
- 今回の公開対象は上記 24 街モデルです。残る 36 街モデルのドラフトと任意 LOD は、カタログ・配布 ZIP・モデル数に含めません。

## English

- Adds 12 original street-infrastructure and pedestrian-access models, bringing the library to 131 assets: 95 models and 36 textures. The city collection now contains 24 models.
- Includes static meter-scaled, Y-up GLB/STL files, thumbnails rendered from the actual models, usage and limitation metadata, and CC BY 4.0 attribution. STL itself does not encode units.
- The immutable archive ledger contains 226 ZIPs and preserves the contents, URLs and hashes of all 202 earlier ZIPs. Existing asset files are unchanged; new ZIPs use selective lossless compression.
- Adds portable production source, dependencies and regeneration instructions, and pins archive generation to Node.js 22.23.3. Ordinary site builds do not regenerate the reviewed models.
- Publication is gated by repository workflow verification of assets, ZIPs, links, textures and browser interactions. This does not establish Unity or other engine compatibility, measured device FPS, manufacturing, structural or 3D-printing suitability.
- This release includes only the 24 public city models. The remaining 36 city drafts and optional LOD supplements are excluded from the catalog, distribution ZIPs and model count.
