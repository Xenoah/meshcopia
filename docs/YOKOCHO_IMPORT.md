# TreeTop Yokocho original asset import

## Scope and selection

60 useful original assets: 39 models (35 baseline-world selections and four entry-plaza additions), plus 21 unchanged texture images. Model groups include seven dimensional signs, distinct chairs and seating/table sets, counters and shelves, lighting, a Noh pavilion, stairs, utility equipment, and four entry furniture/signage models. Sets remain sets when the authored mesh batches combine multiple pieces; repeated placements are not inflated into duplicate entries.

The upstream baseline is [Xenoah/vrcworld_jujo-yokocho at 97091c96cf66a0f67b952827a753a448768f175a](https://github.com/Xenoah/vrcworld_jujo-yokocho/tree/97091c96cf66a0f67b952827a753a448768f175a), release v2.19.0. The source GLB exceeds GitHub's individual-file limit and is present in the [source release ZIP](https://github.com/Xenoah/vrcworld_jujo-yokocho/releases/download/v2.19.0/TreeTopYokocho_v2.19.0_checkpoint1_source.zip), not the repository tree.

Archive: 239,756,388 bytes; SHA256 `d8699d41f30ff9edd2d172bc12f683fb07a4a6eb1e499fdc5b67c5bbeedf2036`.

Every asset records exact source object names or original image paths, source hashes, generator paths, changes and structured source usage. A source usage record establishes authored project provenance, not a claim that a particular VRChat world was deployed or tested.

## Geometry and materials

Source positions, indices, normals, UVs and authored vertex colors are preserved. Root translation centers X/Z and grounds the model at Y=0; original world yaw and component arrangement are retained. Units are meters, Y-up. Triangle counts and dimensions are measured from the actual files. Original UVs may overlap or exceed 0–1; no new unwrap or lightmap UV2 is claimed.

Original plain PBR materials are retained. Verified authored cloth, printed artwork, tile and paper PNGs are embedded byte-for-byte, replacing resized/JPEG encodings of the same imagery in the world GLB. Samplers remain as authored. This does not promise ordinary seamless-repeat behavior. Per-asset provenance lists preserved and replaced materials.

External Poly Haven Bark Brown02, Wood Planks Grey, Wood Table001 and Rocky Terrain02 scan families are not Meshcopia originals and are not redistributed in this collection. Affected model materials use explicitly named textureless neutral PBR replacements. Original early procedural bark/wood maps are separate authored work, not those scans and not newly photorealistic materials.

STL copies contain geometry only, without colors, textures, UVs or encoded units; interpret their coordinate values as meters. These are static game/VR visual assets, not validated for 3D printing or manufacturing. No Unity, collision, rigging, animation, gameplay, runtime lighting or deployed-world validation is claimed.

## Texture images

21 original images are distributed unchanged. Nine use explicit mirrored repeat, with alternating horizontal/vertical tile flips; ordinary Repeat is not promised. Twelve are clamp artworks/cards/atlases, nonseamless and presented at their original aspect ratios. Only base color is advertised; no fabricated PBR maps or ambiguous standalone ARM/normal channel mappings are included. Alpha foliage retains its original transparency.

Eleven non-font baseline images and all eight entry source images were independently regenerated byte-identically. Historical font-rendered baseline sign/menu PNGs are retained from the approved source; they are not claimed to regenerate identically with newer subset fonts. Klee/Yomogi OFL font software is not distributed or relicensed; the rendered artwork is the output of that software, not a font binary.

## Entry plaza

Four models and four standalone textures come from a separate authored entry-plaza snapshot. They are not falsely assigned the baseline v2.19.0 commit. The source `Preview/EntryPlaza.glb` has SHA256 `954520c4fbb5bd4366f875ce5c555b9db8016111f6d5b09349dded2005c0db53`; the original `Source/build_entry_plaza.py` has SHA256 `677b5c6e0f0e7e8d8dbcb60d2d60c312dd4440a0f169c69eaf476dd362c542c4`. Per-asset metadata identifies the original paths and image hashes. Published model sources are self-contained GLBs and STLs. The static display frame does not include working controls or runtime behavior.

## Deliberate omissions

- The fairy confection sign spans a disconnected 5.54 m storefront/pennant arrangement and is not a useful coherent standalone model.
- The bottle shelf omits its Bronze batch, which combines a detached label-display grid with minor brass details/caps. Remaining source geometry is unchanged.
- Repeated chairs, the second matching entry bench, repeated stair bands, cloud/terrain masses and arbitrary whole-world chunks are omitted rather than inflating counts.
- Standalone entry headers and three text-only warp labels are omitted as trivial variants; original images may remain valid dependencies in relevant models.
- External scans, unapproved AI bark studies, font binaries and SDK/runtime files are excluded.

## Reproduction and verification

`import-yokocho-source.py` follows the repository's established one-time source-import workflow. It downloads only the exact released source ZIP, verifies size and SHA256 before extraction, reads only selected original files, and executes `scripts/yokocho/extract-models.py`. Every produced source file must match a reviewed SHA256 in `docs/yokocho-import-plan.json` before inbox import. The script never commits generated website/API/download artifacts. The workflow's existing contents-write permission is unchanged.

Local preparation used the normal new-asset scaffold, inbox dry run and apply. Tests verify glTF validity, actual triangles, STL dimensions/grounding, embedded PNG provenance, unchanged standalone pixels, mirror/clamp semantics, ZIP attribution/licenses and generated links/hashes. Thumbnails are actual exported GLB renders or actual source-image previews, not concept images. Browser CI exercises every new asset and preserves screenshots; release/Pages success must be checked separately before reporting publication complete.
