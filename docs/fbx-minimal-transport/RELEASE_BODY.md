Minimal FBX downloads for the original 137 public models.

Each model has an unchanged reviewed FBX file and a minimal ZIP containing only that FBX and one LICENSE.txt with attribution and conversion notice. Existing immutable archives and original source versions remain unchanged. fbx-minimal-inventory.json provides exact file sizes, hashes and retained notices for download binding. No QA reports, scripts, production metadata or logs are release attachments.

The verification run performed fresh Blender import/export and clean reimport, including imported packed-image byte checks. Transport rechecked the exact reports and FBX container bytes; it did not rerun Blender. Blender-to-Blender evidence does not establish Unity/Unreal compatibility. FBX material conversion has documented PBR limitations; tangents are recomputed by consumers. New assets and textures are outside this cohort.
