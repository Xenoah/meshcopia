# Meshcopia 1.10.0 — Minimal downloads and selected asset ZIPs

The original 137 models and 36 textures now use one ordinary asset ZIP with usable source files, required dependencies and one short LICENSE.txt. The new immutable packages are hosted in the minimal-v1.0.0 release. Existing asset versions, raw source bytes and historical archives are preserved.

Select multiple available assets using the catalog controls. The top-right count opens the selected list with individual removal, clear and download controls. The combined ZIP contains one folder per asset and one root license file with each asset's retained attribution; no nested ZIPs or production reports. Download size limits, cancellation, integrity checks and explicit save prevent silent partial results.

Shared production rules now require FBX in each new or updated model's complete deliverable set, with source-bound clean-import QA. This release does not claim new232 or FBX download availability. Their independent verification and publication remain separate.

Publication requires the canonical archive runtime, unchanged historical archive hashes, complete site validation, texture checks, browser interactions, real minimal download and bulk ZIP verification, and the existing Pages size budget. Browser evidence distinguishes real live downloads from isolated fixture-only error tests.
