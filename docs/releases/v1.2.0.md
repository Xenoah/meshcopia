# Meshcopia 1.2.0

汎用オリジナルメッシュ12点と、単体テクスチャ9点を追加しました。
合計47素材（3Dモデル32点、テクスチャ15点）。すべてCC BY 4.0。

## 追加素材

- メッシュ: ローテーブル、円形ステージ、AV機材ラック、ワークカウンター、
  コーヒー袋、ボトル6本、本6冊、テーブルキャンドル、リング照明、
  ポスターフレーム、スラットバーカウンター、壁付け本棚。
- 鏡像リピート6種: オーク、漆喰、テラゾー、黒皮鋼、真鍮、ティールの織布。
- 非タイルのアトラス3種: RELAY R2操作面、架空ボトルラベル、カフェ小物プリント。

固定コミット `784e040a866c0081d6641c03cbf7f23d48a59dc2` の原形状・元PNGを使用。
メッシュはGLB/STL、画像は元のPNGをそのまま配布。ZIPには出典とライセンスを同梱。
既存のメッシュ・画像は変更していません。

## 表示と取得

通常リピート、鏡像リピート、Clampを区別。鏡像タイルは交互に反転し、球体でも
同じ反復設定を使用します。アトラスは元の縦横比で表示。ベースカラーのみの素材に
存在しないPBRマップを表示しません。

**API変更:** `schemaVersion: 2.0.0`。テクスチャの `width` / `height` と `wrapMode`
を確認してください。`resolution` は長辺、`seamless` は指定方式での連続性です。

## 検証と画像

公開ワークフローはGLB検証、画像ハッシュ、各方式の境界検証、ZIP/リンク、
Chromiumでの全Commonsモデル・追加テクスチャ表示を通過した場合だけ公開します。
添付PNGは実際のWebGLビューアとサイトの画面です。モデルのサムネイルは
実際の抽出メッシュをBlender Cyclesで描画。Unity/VRChat実機・3Dプリントは未検証。
