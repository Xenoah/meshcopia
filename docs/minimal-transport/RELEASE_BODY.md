Minimal downloads for the original 137 models and 36 textures.

Each ZIP contains the usable asset files at the top level, required dependencies where relative paths require them, and one LICENSE.txt with attribution. Source files and asset versions are unchanged. Production scripts, metadata, previews and validation reports are omitted. Existing download archives remain unchanged.

The 173 ZIPs use package version 1.0.0. minimal-inventory.json provides exact download sizes, hashes, source bindings and license notice text for the website. Internal QA is not a release attachment. This release does not include new assets or FBX derivatives.
