# Meshcopia 1.1.0-rc.1 — Commons cafe originals

[素材ライブラリ](https://xenoah.github.io/meshcopia/?q=commons#catalog) に、
**オリジナルの3Dモデル12点**を追加。合計 **3Dモデル20点・シームレステクスチャ6点**です。
すべてCC BY 4.0で、ZIP・モデルのみZIP・GLB単体をダウンロードできます。

## 追加素材

バースツール、ラウンジチェア、2人掛けソファ、カフェ丸テーブル、
ペンダントライト、コーヒーカップ、観葉植物、エスプレッソマシン、
コーヒーグラインダー、PAスピーカー、DJコントローラー、展示台。

[Xenoah/vrcworld_tech-tech-cafe の固定コミット](https://github.com/Xenoah/vrcworld_tech-tech-cafe/tree/784e040a866c0081d6641c03cbf7f23d48a59dc2)
にあるBlenderデータから、独立して再利用できるメッシュを抽出しました。
原点を底面中央にそろえ、m単位・Y-upのGLB/STLを収録。
生成オリジナルのテクスチャはGLBに埋め込み、元画像とのSHA-256一致を検査します。
元コミット、オブジェクト名、出典、変更内容も各素材に記録しています。

## 表示と検証

- 実際の抽出モデルからレンダリングしたサムネイル。
- 元リポジトリ・抽出スクリプトへ遷移できる出自表示。
- 素材数の増加に対応した一覧・検索のテスト。
- Khronos glTF Validator、GLB/STL構造、全配布ファイルのハッシュ、ZIP内の依存・クレジットを確認するゲート。
- CI Chromiumで追加12点すべての3D表示を検査し、スクリーンショットを添付。

## 素材の範囲

外部SDK・車両・ドローン・フォント・ポスター・動作スクリプトは含みません。
建築用の元画像はMirror反復を保持し、通常Repeatのシームレステクスチャとして登録していません。
今回の機材・照明は装飾モデルです。STLは色・材質・UVを持ちません。
Unity/VRChat実行、実機、3Dプリント用途は未検証です。
