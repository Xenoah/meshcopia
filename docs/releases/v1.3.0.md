# Meshcopia 1.3.0 — TreeTop Yokocho originals

60 new original assets: 39 self-contained GLB/STL models and 21 unchanged texture images. The library now contains 71 models and 36 textures, 107 assets total.

- Dimensional shop signs, distinctive furniture and seating sets, bar equipment, shelves, a Noh pavilion, timber stairs, utilities and entry-plaza furniture/signage.
- Actual render thumbnails, measured triangles/dimensions, original UVs and image hashes, honest material-substitution and static-use limits.
- Nine explicitly mirrored-repeat basecolors and twelve nonseamless clamp artworks/cards/atlases. No external scan images, unapproved AI bark or font software.
- Structured source/usage records distinguish original creation from later reuse and preserve known project, source URL/ref, source paths and object selectors without inventing deployment history.
- Digest-pinned one-time import, local aggregate checks, GLB validation and CI WebGL/mobile interactions. Every ZIP includes attribution and CC BY 4.0 license text.

See [Yokocho import provenance and limitations](../YOKOCHO_IMPORT.md). Models are static game/VR assets; no Unity, manufacturing or 3D-printing validation is claimed. STL coordinates are meters but the format does not encode units. Entry models are separately identified authored additions, not falsely attributed to the baseline release commit.
