Original generic street tree with a root flare, tapered branching hierarchy, fine bearing shoots and individually folded leaf blades. Its irregular rounded crown represents pruning without claiming a particular species. Leaves are thin double-sided surfaces; no wind animation, LODs or species accuracy is supplied. For games and visualization; not validated for manufacture, structural engineering or 3D printing.
