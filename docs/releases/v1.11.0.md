# Meshcopia 1.11.0 — Verified FBX downloads

The original 137 published models now offer an additional FBX download and a minimal FBX ZIP containing exactly the model and LICENSE.txt. The immutable fbx-minimal-v1.0.0 release supplies these downloads. Ordinary asset ZIPs, original format links, selected-asset bundles and the accurate ZIP-size display remain available.

FBX is a static, meter-unit, Y-up interchange format with embedded images. Materials, transparency and face culling can vary by importer. Prefer GLB when you need the original PBR appearance. Blender clean-import evidence does not establish matching appearance in Unity, Godot or every other importer; tangent export and single-sided culling remain documented limitations. The browser preview uses the existing original formats, not FBX rendering.

Site availability requires the exact successful F/R verification identities, source and asset-version matches, the durable transport attestation, all 275 anonymous public attachment byte checks, and a fresh same-job single-use build receipt. No production token or expiring internal QA artifact is needed. Failure stops publication; there is no fallback activation.

Publication gates include the canonical archive runtime and unchanged historical archives, complete site checks, texture validation, original viewer and selected-download browser regressions, all 137 FBX page links, six representative real anonymous FBX/ZIP browser downloads, mobile and no-JavaScript links, and the Pages size budget. Build and browser results are recorded by the exact verification run; this document does not itself assert a successful run. No new model cohort is included.
