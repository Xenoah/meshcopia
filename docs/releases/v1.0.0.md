# Meshcopia 1.0.0 — First release

人間とAIエージェントが無料で取得できる、3Dモデルとシームレステクスチャの保管場所。
オリジナル素材はすべて **CC BY 4.0**。商用利用・改変・再配布に対応します。

## 収録と機能

- 3Dモデル8点: GLB、OBJ/MTL、STL。単位m / Y-up / 実際のモデルから生成したサムネイル。
- シームレステクスチャ6点: 各1024px、Base Color・Normal・Roughness・Height。
- 名前・タグ・形式検索、種類・カテゴリー絞り込み、並び替え、共有可能な検索URL。
- 3Dクイックプレビュー、回転・拡大・材質・照明・ワイヤー。非表示ビューアを停止。
- テクスチャの1×1・2×2・4×4タイル確認、PBR球体と各マップ表示。
- 全体ZIP／モデルのみZIP／単体ファイル。ライセンスとクレジット同梱、クレジットコピー。
- 静的JSON/NDJSONカタログ、個別マニフェスト、SHA-256、`llms.txt`、`AGENTS.md`。
- `_inbox`への投入から検証・取り込み・カタログ・ZIP・配信物を自動生成。
- モバイル対応、キーボード操作、主要UI・素材の日本語/英語切替。

## RCからの改善

- スマホでダウンロード欄をプレビュー直下へ移動。
- 別モデルへのプレビュー切替で、ワイヤー・材質・照明の表示状態をリセット。
- 全サムネイルのデコードを待ってQAスクリーンショットを記録。

## 検証

- メタデータ・CC BY・ソースのパス・GLB/STL構造・検索・ZIPの自動テスト。
- 配布ファイルとZIPの86件のSHA-256・サイズ、全ZIPのライセンス・依存ファイルを確認。
- 生成サイトの内部リンクを検証。
- 24枚のマップすべてで画像サイズと両端ピクセルの一致を確認。
- CI Chromium: PC/スマホ、検索・フィルター、プレビュー再利用、GLB/STL/OBJ、材質・照明、ZIPの実ダウンロード、クリップボード、テクスチャ切替・PBR球体、言語切替、横はみ出し無し。

## ダウンロード

- `*-all.zip`: 全14素材のパッケージ。
- `*-models.zip`: 3Dモデル8点のパッケージ集。
- `*-textures.zip`: シームレステクスチャ6点のパッケージ集。
- `*-site.zip`: ビルド済み静的サイト。`/meshcopia/` 配下で配信。
- `catalog.json` / `SHA256SUMS`: 機械可読カタログとアーカイブ検証用。
- PNG: CIで取得した実画面スクリーンショット。

## 公開設定と制限

GitHub Pagesの初回有効化はリポジトリ管理者の設定が必要です。連携の権限では
`Create Pages site` が `Resource not accessible by integration` となりました。
**Settings → Pages → Source: GitHub Actions** を選び、失敗したPagesジョブを再実行すると
ビルド済みアーティファクトを公開できます。素材はこのReleaseからすぐ取得できます。

予定URL: https://xenoah.github.io/meshcopia/

初期素材は軽量なプロシージャル素材で、実写スキャンではありません。
UVは基本的な平面投影。3Dプリント・機構用途は未検証です。
FBX/STEPプレビューは継承実装ですが、初期素材に該当ファイルがないため
ブラウザでの実データ試験はGLB/STL/OBJのみです。

この正式版はプレリリース `v1.0.0-rc.1` に続く初回安定版です。
