# Meshcopia 1.9.0 - Compact mobility and street fixtures

## 日本語

- 独自の街用モデル 6 点を追加。全体は 173 素材（137 モデル、36 テクスチャ）、街コレクションは累計 66 モデルです。
- メートル・Y-up の静的 GLB と STL、実際のモデルから描画したサムネイル、用途・実寸・限界を明記したメタデータ、CC BY 4.0 と作者表示を収録。STL 自体には単位情報がありません。
- 累計 310 ZIP のハッシュを固定し、先行 298 ZIP の内容・URL・ハッシュと既存公開素材を維持します。
- 公開はリポジトリのワークフローによる素材・ZIP・リンク・テクスチャ・ブラウザ操作の検証を条件とします。Unity 等の実機互換性、FPS、製造・構造・3D プリント用途は未検証です。
- 未公開の街モデル 0 点と、別配布の任意 LOD はカタログ・配布 ZIP・モデル数に含めません。元モデルを維持し、自動 LOD 切替を実装するものではありません。

## English

- Adds 6 original city models, bringing the library to 173 assets: 137 models and 36 textures. The city collection now contains 66 models.
- Includes static meter-scaled Y-up GLB/STL files, actual-model thumbnails, purpose/dimensions/limitation metadata and CC BY 4.0 attribution. STL itself does not encode units.
- The cumulative ledger contains 310 ZIPs, preserving all 298 earlier ZIP contents, URLs and hashes, plus previously public assets.
- Publication is gated by repository workflow verification of assets, ZIPs, links, textures and browser interactions. No Unity/engine compatibility, measured FPS, manufacturing, structural or 3D-printing validation is claimed.
- The 0 unpublished city drafts and separately supplied optional LODs are excluded from the catalog, distribution ZIPs and model count. Originals remain; automatic LOD switching is not provided.
